# Factory and OTA packages

Flashwright can open a Pixel factory zip or a full A/B OTA zip, extract `init_boot` or `boot`, and check hashes. The call writes only into the directory the caller names. It does not talk to a phone.

The public entry point is `flashwright_core::firmware::open_package`.

## What is accepted

- A `.zip` package only. `.tar`, `.tgz`, and `.tar.gz` are refused.
- A full OTA: `payload.bin` stored uncompressed, `ota-type` `AB`, and no `pre-build`.
- A factory zip: one nested `image-*.zip`, plus the factory flash script.
- Pixel 9 Pro XL (`komodo`) is an `init_boot` phone. Older phones that have only `boot` use that image. If the phone and the package disagree, extraction stops.
- The LU0 and FIPS regions are refused before anything is extracted.

## Checks

- The package SHA-256 is computed in 1 MiB reads. Progress is reported every 64 MiB.
- The last 8 hex digits in the file name must be a prefix of that SHA-256.
- When the caller supplies Google's published SHA-256, it must match the package. The comparison is case-insensitive.
- The file name, `android-info.txt` (`require board=`), or OTA `pre-device` must name the same phone. `eos` and `aurora` compare equal.
- An OTA partition hash is the SHA-256 in the payload manifest, read from the AOSP proto. The extracted image must match it.
- A factory image must pass its CRC-32 and parse as a boot image with an AVB footer. When the package states a security patch or a fingerprint, the footer properties must match.
- When the caller supplies the phone's build time or security patch, an older package is refused.
- Free space must cover the inner zip, the extracted image, and 1 GiB.

Copying uses 64 KiB buffers. One partition is extracted. The worker ceiling is the smaller of 4 and the host's parallelism.

The payload-dumper proto is kept for comparison and is not compiled. The unlicensed Python `payload_dumper` is not used. Platform-tools, `update_engine_client`, `avbctl`, and `aapt2` are not bundled.

## Tests

CI uses synthetic packages. Set `FLASHWRIGHT_KOMODO_IMAGE` to a factory zip you already have to run the opt-in check. `FLASHWRIGHT_KOMODO_SHA256` is optional and is the published package checksum. CI leaves both unset.

A 14 GiB fixture and a multi-gigabyte throughput measurement are not part of CI. The free-space check is a comparison, including a request larger than this volume, and the hash buffer sizes are fixed in code.
